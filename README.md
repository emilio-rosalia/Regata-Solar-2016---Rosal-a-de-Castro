# Regata-Solar-2016---Rosal-a-de-Castro

En este proyecto están los archivos y documentos creados por los alumnos para crear el barco solar con el que participar en la [Regata Solar](https://aindustriosa.org/regatasolar/).

## Principios de diseño

Los principios de diseño en los que se han apoyado los alumnos son:

- Reutilizar materiales para reducir el impacto del proyecto.
- Que el diseño permita un fácil acceso a los diferentes componentes con el fin de facilitar las reparaciones.

## Control de potencia

Para el proyecto se ha utilizado una placa para controlar la potencia que suministra la placa solar y evitar que el sistema se apague por un exceso de consumo.

Para implementar este control se ha tomado como referencia el proyecto de GitHub de los organizadores:

- https://github.com/aindustriosa/Solar_MPPT_board/blob/master/RegataSolar2026.md
